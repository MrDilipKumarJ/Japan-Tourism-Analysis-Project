# 📊 Visualizations Directory

This folder contains all output visualizations and interactive maps from the analysis.

## Files

- **japan_visitors_map.html** - Interactive choropleth map showing global distribution of visitors to Japan
  - Color intensity represents visitor volume
  - Hover for country-specific data
  - View directly in any web browser

## Generated Charts

The following visualizations are generated when running the notebook:

1. **Top 10 Countries Bar Chart** - Horizontal bar chart showing visitor counts
2. **Visitor Distribution Pie Chart** - Continental breakdown of visitors

## How to View

### Interactive Map
Simply download and open `japan_visitors_map.html` in your browser to explore the interactive visualization.

### Static Charts
Run the notebook (`notebooks/Japan_Tourism.ipynb`) to generate and view these in Jupyter.
