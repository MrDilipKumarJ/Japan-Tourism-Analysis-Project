# 📓 Notebooks Directory

This folder contains all Jupyter notebooks for the Japan Tourism Analysis project.

## Files

- **Japan_Tourism.ipynb** - Main analysis notebook containing:
  - Data loading and cleaning
  - Exploratory data analysis (EDA)
  - Visualizations (bar charts, pie charts)
  - Interactive choropleth map generation

## How to Run

1. Ensure you have all dependencies installed (see root README.md)
2. Open the notebook in Jupyter:
   ```bash
   jupyter notebook Japan_Tourism.ipynb
   ```
3. Execute cells sequentially
4. Output files will be saved to the `visualizations/` folder
